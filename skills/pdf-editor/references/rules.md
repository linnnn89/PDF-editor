# Editing rules and capability boundaries

- Preserve original PDFs. Write new absolute paths on a destination supporting the engine's non-overwriting publication (NTFS); never overwrite the source or an existing result. Confirm results from the saved output, not just a plan or successful import.
- Use the opened `source.sha256` / plan `sourceSha256`, inspected object IDs, and exact `textSource` preconditions. Reader-extracted `text` can contain inferred spaces and is not a substitute. Require actual editability and `supportedOperations`; do not force unsupported or ambiguous objects.
- Preserve numerical results, statistical notation, labels, and scientific meaning outside the user's requested changes. A typography task does not authorize recalculation, altered analysis sets, removed rows, or revised evidence. If the user expressly requests a substantive change, apply that scope rather than treating all content as immutable.
- Text replacement preserves its baseline origin but lays out the new whole string without the old internal manual kerning. `text.style` retains internal adjustments. No automatic fitting, semantic row grouping, OCR, image replacement, font-family switching, text outlining, or figure creation from data is provided by this engine. Do not claim these capabilities or silently substitute raster overlays.
- Font size is `(0,300]` pt; line width is `[0,100]` pt; write colors as `#RRGGBB`. Font availability, embedding permissions, and encoding are validated by the engine. Do not install fonts or evade restrictions. Inspect the exact error and the checkout's font support contract before proposing a scoped alternative.
- Geometric bounds and pixel gates have defined limits; they do not prove a label belongs to a study, guarantee freedom from overlap with neighboring objects, or replace visual inspection. Cropping and composition retain potentially recoverable hidden content and must not be presented as anonymization.
- Full receipts and error details may contain document text and local font paths. Keep them local unless sharing is authorized; compact summaries still may reveal paths. Report completed operations, verification actually performed, and meaningful unsupported behavior without claiming client hot reload or live integration from a copied skill.
